# SEO 키워드 발굴 지침 (dailyengtips.tistory.com)

실생활 영어 블로그의 성장을 위해 정보탐색형 롱테일 키워드를 발굴합니다.

## 발굴 전략
1. **10년차 영어 교육 SEO 전문가** 페르소나를 활용하세요.
2. **정보탐색형 키워드**: 사용자가 영어 표현에 대해 궁금해하는 '차이', '뜻', '사용법', '실수' 위주의 키워드를 찾으세요.
3. **최신 트렌드 반영**: Google Search Grounding을 사용하여 인기 미드, 영화, 시사 이슈에서 나온 영어 표현을 반영하세요.
4. **키워드 제외**: 토익/토플 점수 올리기, 문법 이론 중심, 학원 광고성 키워드는 제외하세요.

## 카테고리 분산 규칙 (필수)
블로그에는 7개 카테고리가 있으며, 키워드 발굴 시 **카테고리 편중을 방지**해야 합니다:

| 카테고리 | 설명 | 현재 비중 |
|----------|------|-----------|
| 일상 회화 | 카페, 식당, 쇼핑 등 생활 속 영어 | 보통 |
| 직장 영어 | 이메일, 회의, 프레젠테이션 표현 | **부족** |
| 여행 영어 | 공항, 호텔, 관광지에서 쓰는 표현 | **부족** |
| 한국식 영어 바로잡기 | 콩글리시, 잘못된 표현 교정 | 보통 |
| 미드/영화 속 표현 | 넷플릭스, 영화 대사에서 배우는 영어 | **부족** |
| 뉘앙스 차이 | 비슷한 단어/표현의 미묘한 차이 | 보통 |
| 발음/리스닝 팁 | 원어민 발음, 연음 규칙 등 | **부족** |

- 매 발굴 시 2개의 키워드는 **서로 다른 카테고리**여야 합니다.
- "일상 회화"와 "한국식 영어"는 이미 보통이므로 가급적 다른 카테고리를 우선합니다.
- "직장 영어", "여행 영어", "미드/영화 속 표현", "발음/리스닝 팁"을 우선 채워야 검색 유입이 다양해집니다.

## 제목 규칙
- "내년부터", "올해부터" 같은 상대적 시간 표현 절대 금지
- "20XX년, ~" 패턴 (연도 + 쉼표/콜론) 금지
- "~의 서막", "~로 진화하다", "~ 완벽 가이드" 같은 AI스러운 제목 금지

## 키워드 예시
- "'I'm fine' 말고 원어민이 쓰는 인사 표현 5가지" → 일상 회화
- "영어 이메일 'Dear Sir' 대신 쓸 수 있는 표현" → 직장 영어
- "공항에서 'boarding pass' 말고 알아야 할 영어 표현" → 여행 영어
- "'spend'와 'waste' 차이 — 돈/시간 쓸 때 구분법" → 뉘앙스 차이
- "넷플릭스 <수요일>에서 배우는 영어 슬랭 5가지" → 미드/영화 속 표현
